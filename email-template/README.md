# Responsive HTML email template (sample)

A promo email for a made-up brand, Northfield Soap Co. Built by hand with tables and inline styles so it holds up in Gmail, Outlook and Apple Mail.

- 600px wide on desktop, stacks to one column on phones
- Hidden preheader text for the inbox preview
- Button built from a table cell, so it shows even with images off
- No images required: product blocks are plain colour panels you can swap for photos

Open `index.html` in a browser to preview it.
