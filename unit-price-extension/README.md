# Unit Price Check (Chrome extension sample)

A small Chrome extension: type the price and size of two products and it tells you which is cheaper per unit, and by how much.

Built with plain HTML, CSS and JavaScript (Manifest V3). It asks for no permissions and sends no data anywhere.

## Try it
1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose this folder.
4. Click the extension's icon in the toolbar.
